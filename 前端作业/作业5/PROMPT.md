# 实现本作业使用的 Prompt

> 用于完成「前端作业 05」的 prompt；实现结果见 `index.html`、`styles.css`、`app.js`。

---

请用 **HTML + CSS + 原生 JavaScript** 实现一个极简响应式数据看板。不要使用框架、构建工具、第三方库、网络字体或外部图片；所有图标使用内联 SVG；双击 `index.html` 即可运行。代码在满足要求的前提下尽量少。

## 硬性要求

1. **三档断点**
   - `< 768px`：单列。
   - `768px – 1199px`：两列。
   - `≥ 1200px`：四列，并显示左侧栏。

2. **卡片布局**
   - 使用 CSS Grid 的 `auto-fit` / `minmax()`（或 `flex-wrap`）。
   - 不能写死 `width: 1200px` 之类的视口宽度。

3. **无横向滚动**
   - 在 `320px–1920px` 全区间不出现横向滚动条。
   - 重点检查 320、360、375、767、768、1024、1199、1200、1440、1920px。

4. **数据由 JS 渲染**
   - 6 个指标：访问量、新增用户、转化率、客单价、支付订单、退款率。
   - 6 条数据放在一个 JavaScript 数组中，用一次循环或一个模板字符串生成卡片。
   - HTML 中禁止出现 6 段重复卡片。

5. **数字排版**
   - 指标值与涨跌幅使用 `font-variant-numeric: tabular-nums`。
   - 数字区域不应轻易抖动。

6. **主题**
   - 用 CSS 自定义属性集中管理颜色。
   - 提供浅色、深色两套主题，并用可见的 `<button>` 切换。

7. **图标**
   - 所有图标为内联 SVG，明确声明 `width` 和 `height`。
   - 描边或填充使用 `currentColor`，跟随主题变化。

8. **语义化**
   - 页面标题用 `h1`，区块标题用 `h2`，卡片标题用 `h3`。
   - 卡片区域使用 `<section>`，主题切换使用真实的 `<button>`。

## 视觉方向

- 安静、克制的浅色数据看板；蓝色作强调色，绿色/红色只表示涨跌。
- 系统 sans 字体，卡片使用细边框、轻阴影和适度圆角。
- 桌面端侧栏包含品牌和少量导航；移动端隐藏侧栏。

## 验收

- [ ] 320–767 单列；768–1199 两列；≥1200 四列且出现侧栏。
- [ ] 320–1920 无横向滚动。
- [ ] 6 张卡片由同一个 JS 数组生成，源码无重复卡片 HTML。
- [ ] 指标值与涨跌幅计算样式为 `tabular-nums`。
- [ ] 深浅主题可切换，切换后按钮文字和 `aria-label` 同步。
- [ ] 所有 SVG 有明确尺寸并使用 `currentColor`。
- [ ] `h1/h2/h3`、`section`、`button` 使用正确。
- [ ] 无框架、无构建步骤、无第三方依赖。
