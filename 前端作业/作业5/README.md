# 前端作业 05 · 响应式数据看板

用 **HTML + CSS + 原生 JavaScript** 实现的极简数据看板：3 个源文件、无框架、无第三方依赖、无网络请求，双击 `index.html` 即可运行。

## 运行

直接双击 `index.html`，或使用任意静态服务器。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 语义结构、侧栏、主题按钮、内联品牌 SVG |
| `styles.css` | CSS 变量、深浅主题、三档响应式布局、卡片样式 |
| `app.js` | 6 条指标数据、单次循环渲染卡片、图标与主题切换 |
| `PROMPT.md` | 实现本作业使用的 prompt |

## 需求对照

| # | 要求 | 实现 |
| --- | --- | --- |
| 1 | `<768` 单列、`768–1199` 两列、`≥1200` 四列 + 侧栏 | 移动优先；`768px`、`1200px` 两个媒体查询；侧栏只在 `≥1200px` 显示 |
| 2 | 使用 Grid `auto-fit` / `minmax()`，不写死 `width: 1200px` | 桌面端 `repeat(auto-fit, minmax(max(190px, calc((100% - 48px) / 4)), 1fr))`；容器自适应 |
| 3 | `320px–1920px` 无横向滚动条 | 实测 12 档宽度，`scrollWidth === clientWidth`，无越界元素 |
| 4 | 6 条卡片数据由 JS 数组渲染 | `METRICS` 数组 + 一次 `.map()` 模板字符串；HTML 中无重复卡片 |
| 5 | 数字使用 `font-variant-numeric: tabular-nums` | 指标值 `.value` 与涨跌幅 `.delta` 均设置 `tabular-nums` 和 `"tnum"` |
| 6 | CSS 变量管理颜色，至少一个深浅主题切换 | `:root` / `:root[data-theme="dark"]` 两套变量；`<button>` 切换，文字与 `aria-label` 同步更新 |
| 7 | 图标明确尺寸，内联 SVG + `currentColor` | 品牌 22×22，卡片图标 18×18；描边或填充均为 `currentColor` |
| 8 | 语义化：`h1/h2`、卡片区 `section`、按钮 `button` | 1 个 `h1`、1 个 `h2`、6 个 `h3`、`<section id="metrics">`、`<button id="theme-toggle">` |

## 自测结果

| 视口 | 列数 | 侧栏 | 横向滚动 |
| --- | --- | --- | --- |
| 320px | 1 | 隐藏 | 无 |
| 767px | 1 | 隐藏 | 无 |
| 768px | 2 | 隐藏 | 无 |
| 1199px | 2 | 隐藏 | 无 |
| 1200px | 4 | 显示 | 无 |
| 1440px | 4 | 显示 | 无 |
| 1920px | 4 | 显示 | 无 |

另测 360 / 375 / 414 / 1024 / 1366px，均无横向滚动；6 张卡片均由 JS 生成，无重复 ID，无 JS 异常。

## 说明

- 数据为课程演示数据，不连接真实接口。
- 所有图标为内联 SVG，页面不加载图片、字体或脚本依赖。
- 主题切换不写入存储，刷新后回到浅色主题。
