## 二、应用到的表单增强（HTML5 表单新特性）

### 1. 新增的 `<input>` 类型（type 属性）

| 类型 | 使用位置 | 作用 |
| --- | --- | --- |
| `type="email"` | 注册邮箱、登录账号 | 自动校验邮箱格式，不合法时无法提交 |
| `type="password"` | 密码 / 确认密码 | 密文显示 |
| `type="tel"` | 手机号 | 移动端自动唤起数字键盘 |
| `type="date"` | 出生日期 | 弹出原生日期选择器 |
| `type="number"` | 入学年份 | 数字输入框，可配合步进 |
| `type="range"` | 每周学习时长 | 滑块控件 |
| `type="color"` | 主题色 | 原生取色器 |
| `type="url"` | 个人主页 | 自动校验 URL 格式 |
| `type="file"` | 头像上传 | 文件选择框 |

### 2. 表单校验与约束属性

| 属性 | 作用 |
| --- | --- |
| `required` | 标记必填项，未填写时阻止提交 |
| `placeholder` | 输入框占位提示文字 |
| `pattern` | 正则表达式校验（用户名、手机号、密码） |
| `minlength` / `maxlength` | 最小 / 最大输入长度 |
| `min` / `max` / `step` | 数值 / 日期范围与步进 |
| `autocomplete` | 自动填充（username / email / new-password 等） |
| `autofocus` | 页面加载后自动聚焦 |
| `accept` | 限制文件上传类型（`image/*`） |
| `multiple` | （预留）多文件 / 多选能力 |

### 3. 新增表单元素

| 元素 | 作用 |
| --- | --- |
| `<datalist>` | 为输入框提供联想候选（专业、历史账号） |
| `<meter>` | 密码强度进度条 |
| `<output>` | 实时显示滑块数值、字数统计等表单输出 |
| `<fieldset>` / `<legend>` | 表单分组与标题，结构更清晰 |

### 4. CSS 校验伪类实时反馈

- `:valid` / `:invalid` —— 输入合法 / 非法时边框颜色实时变化（绿 / 红）
- `:focus` —— 聚焦高亮，提升交互体验
- `::file-selector-button` —— 自定义文件选择按钮样式

## 三、其他 HTML5 相关能力

| 能力 | 使用位置 | 说明 |
| --- | --- | --- |
| `<canvas>` | 登录页图形验证码 | 使用 Canvas 绘制随机验证码（背景、干扰线、旋转字符） |
| 语义化标签 | 整体结构 | `header/fieldset/label` 等语义清晰，利于可访问性 |
| CSS3 渐变 | 全局背景、按钮、标题 | `linear-gradient` / `radial-gradient` 营造 AI 科技氛围 |
| 响应式设计 | `style.css` | 使用 `@media` + `flex` 自适应手机 / 桌面 |
| CSS 变量 | `:root` | 统一主题色，便于维护 |
| `backdrop-filter` | 卡片 | 毛玻璃效果 |
